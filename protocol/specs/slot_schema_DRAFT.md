# Slot schema — DRAFT / UNFROZEN

The slot renderer/parser must be executable and frozen before Stage 1.

For every role define:

- exact field label;
- allowed output vocabulary, if constrained;
- UNKNOWN handling;
- canonical parser;
- unit/granularity rule;
- whether the analytic chance reference is exact or only nominal.

The primary receiver prompt must not prohibit use of parametric knowledge, because reconstruction after omission is itself a target mechanism.
