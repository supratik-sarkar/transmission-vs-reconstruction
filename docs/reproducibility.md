# Reproducibility and integrity

## The freeze chain

Acyclic by construction. Step 3 cites step 2; never the reverse.

1. freeze prompts, specifications, code, support files and source artifacts
2. hash them into an **artifact manifest**
3. finalise the pre-registration, which **cites** the manifest hash
4. create a **freeze record**: pre-registration hash, manifest hash, source-pool
   hash, commit, model versions, UTC timestamp
5. verify before running
6. record every deviation

The manifest carries a self-hash, so editing the manifest itself is detected.

## Two records

**Protocol freeze**, before the discovery stage. Binds the source-frame rule, the
window, the budget, the task text, the atomizer, the sampler, the receiver, the
matcher, the editor, randomisation supports, the skeleton rule, the gates, the
bootstrap, the comparator suite and the comparative rule.

**Final-test freeze**, before any final-test execution. Additionally binds the
test documents, focal samples, atom inventories, model versions, the receiver
prompt, comparator revisions, the fitted policy artifact, the feature schema, the
renderer, budgets, the tokenizer, the analysis code, the table generators, the
figure generators, the bootstrap code and the comparative rule.

No final-test runner executes without a valid record. Incomplete fields are a
hard error, and placeholders such as `TBD`, `PROPOSED` or `UNFROZEN` count as
incomplete — blanks are blanks by design, and filling them with a plausible
string would make the record false at signing.

## Determinism

Decoder regime (D) is a **claim about an endpoint, not a configuration flag**.
Setting temperature to zero does not make a hosted service deterministic. The
audit issues the same request repeatedly at the same configuration on disjoint
calibration prompts and requires **exact** output agreement.

If agreement is not exact, the receiver must not be labelled regime (D). The
options are a genuinely deterministic receiver, or a revised pre-registration
under regime (S) — under which atom-level statistics that are nonlinear
functions of the surplus are not identified from one query per availability.

All randomness derives from one master seed plus a stage label, so a run is
reproducible from two integers and a string.

## Results provenance

`RESULTS_MANIFEST.json` maps every table, figure and reported metric to the run
identifiers, source hashes, configuration hashes, model revisions, comparator
revisions, analysis version and exporter version that produced it.

No artifact without provenance is accepted for export. Every empirical table and
figure is generated by code from structured result artifacts; no number is typed
in by hand.

Plotting functions refuse empty input rather than drawing an illustrative curve.
Fixtures for dry runs are stamped `SYNTHETIC TEST FIXTURE` on the canvas, so a
fixture can never be mistaken for a result.

## Manuscript guard

`handoff manuscript-check` fails on unresolved placeholders, missing generated
fragments, missing figure files, undefined citations or references in the build
log, and assets absent from the results manifest.

It distinguishes intentionally **static conceptual** diagrams — schematics drawn
once by hand, which are not results — from unresolved **experimental** figures.
Demanding a generated file for a conceptual diagram would push toward fabricating
one.

The guard never makes itself pass by inventing data. A failing check means run
the experiment, not fill the placeholder.

## Privacy and secret boundary

`handoff privacy-scan` fails the build if a **tracked** file contains
machine-specific filesystem paths, credential patterns, real contact addresses,
private workspace or run directories, internal tooling instructions, or
venue-and-submission language in the public documentation.

Two deliberate design points:

- The scanner is allowlisted against itself and its own test. It must contain the
  patterns it looks for, and obfuscating them to dodge its own check would make
  the rules unreadable, which is worse.
- Venue names are legitimate content in a bibliography. They are flagged only in
  the public prose, where they would make the repository read as a submission
  workspace rather than as research software.

Credentials are read from the environment only, never accepted as arguments,
written to disk, logged or included in a repr. Diagnostics report only *whether*
a credential is present.

The private runtime workspace must remain outside the repository and must not be
a Git repository. Both are checked, because either failure turns one `git add -A`
into a disclosure.

## Continuous integration

CI runs deterministic checks only: compile, lint, type check, tests, design
invariants, privacy scan, secret scan, and an assertion that no runtime artifact
directory is tracked.

CI has no credentials, makes no provider call, clones no restricted repository
and runs no experiment.

## Deviations

Any departure from a frozen value is recorded with the date, the reason and the
effect on interpretation. A deviation is a disclosure, not a repair.
