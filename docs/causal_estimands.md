# Causal estimands

## Units

Documents are indexed `i`. Each document has a finite **atom inventory** built
from exactly the relay-visible source frame. An *epistemic atom* is a
canonically valued semantic unit: a named entity, a scope or segment label, a
period, a numeric value, or a reference to a note or exhibit.

A **relay** maps the source to a message under a token budget. A **receiver**
maps the message to an output from which each atom's value is elicited through a
fixed slot schema.

- `T_iz ∈ {0,1}` — whether atom `z` appears in the message
- `M_{i,-z}` — the remaining message content
- `Y_iz ∈ {0,1}` — whether the elicited value matches the source value

## The sender assigns treatment

Let `W_iz` denote the **availability** of `z` in the message handed to the
receiver, and `Y_iz(w; M_{i,-z})` the corresponding potential outcome.

In an uninstrumented run the sender chooses availability, so `W_iz = T_iz`. This
is an observational study whose assignment mechanism is a language model, and it
is **not ignorable**: a relay that drops predictable content assigns `W = 0`
preferentially to atoms with high `Y_iz(0)`.

That single observation is what makes the whole problem causal rather than
statistical.

## Atom-level estimands

Holding the natural non-focal content fixed:

```
R^-_iz  = E[ Y_iz(0; M_{i,-z}) ]     focal-omission reconstruction baseline
D^+_iz  = E[ Y_iz(1; M_{i,-z}) ]     recovery under explicit transmission
Δ^av_iz = D^+_iz − R^-_iz            availability transmission surplus
```

The expectations are over receiver randomness alone.

`R^-` is **not** a no-communication floor: every non-focal atom remains present.
The no-communication counterfactual is a different object and is not estimated.

Population quantities under the focal-sampling design:
`R̄₀ = E[R^-]`, `Δ̄ = E[Δ^av]`, `T̄ = E[T]`, `A = E[Y^obs]`.

## Assumptions

Four, each load-bearing for a stated result, each with an observable
diagnostic.

**A1 — Consistency and confined interference.** The realised outcome equals the
potential outcome at the realised availability, and an availability intervention
alters the message only through the presence of `z`. *Diagnostic:* the editor's
non-focal invariance is checked mechanically on every edit.

**A2 — Design-based focal selection and positivity.** Focal atoms enter through a
selection indicator generated by fixed-size role-stratified sampling without
replacement, with `π_iz > 0` for every atom in the target population, drawn
independently of relay and receiver randomness and never revealed to the relay.

Note carefully what is *not* assumed. We do **not** assume `z ⊥ T` — that is
false, and the dependence is the object of study. The independence needed is of
the *selection indicator*, which is what a design-based argument requires.
Conflating the two is a genuine error, and an earlier draft of this work
contained it.

**A3 — Decoder regime.** Either **(D)** the receiver decodes deterministically at
a pinned configuration, so `R^-` and `D^+` are `{0,1}`-valued; or **(S)** the
receiver is stochastic and they are conditional expectations. The two regimes
support **different** identification claims.

**A4 — Edit neutrality.** The editing operation affects the receiver only through
the availability of `z`. This is the weakest assumption and the only one on
which an empirical claim depends. The sham placebo is a negative control on the
*mechanical* component of the artefact only — it cannot establish the exclusion
restriction, because a semantics-preserving edit does not vary the content whose
removal is at issue. The burden is carried by partial identification.

## The decomposition

```
A  =  R̄₀  +  T̄·Δ̄  +  Cov(T, Δ^av)
```

Elementary — the law of total expectation for a binary treatment. No algebraic
novelty is claimed. Its content is that the three terms are separately
**identifiable by intervention** and answer different questions:

- `R̄₀` — what the receiver supplies
- `T̄·Δ̄` — what transmitting at the observed rate buys
- `Cov(T, Δ)` — **assignment–effect alignment** between transmission decisions
  and the surplus they realise

The name is chosen carefully. A positive covariance says transmitted atoms tend
to carry larger surplus: an association, not evidence of deliberate or efficient
allocation. Whether a scarce budget is allocated *well* is answered only by the
budget-neutral benchmark.

`C_comm = A − R̄₀` is reported **signed**. `Δ^av < 0` is admissible — including an
atom can reduce recovery through distraction or interference — so `φ = C_comm/A`
is a normalised derivative when `A > 0`, never "a share".

## What endpoints cannot reveal

The observed law fixes only `(T̄, d₁, r₀)` where `d₁ = E[D^+ | T=1]` and
`r₀ = E[R^- | T=0]`. The counterfactual means
`r₁ = E[R^- | T=1]` and `d₀ = E[D^+ | T=0]` are never realised in an
uninstrumented run and are left entirely unconstrained. Each of `R̄₀`, `Δ̄` and
`Cov(T, Δ)` is a non-constant affine function of `(r₁, d₀)`, so a two-parameter
family of causal worlds induces exactly the same observed law while realising
different values of all three terms.

## What one intervention buys

Query the receiver once under the observed availability and once under
`W = 1 − T`.

- Under **(D)** this point-identifies the atom-level `R^-`, `D^+` and `Δ^av`.
- Under **(S)** one query per availability does **not** recover the atom-level
  conditional expectations, but yields unbiased design-based estimating
  equations for the population quantities, because receiver noise has
  conditional mean zero and `T` is atom-measurable.

Minimality is an **atom-level** statement under (D). At the population level a
randomised second-phase subsample with known `q_iz > 0` suffices; instrumenting
every sampled atom is a precision choice, not a necessity.

One design consequence follows immediately: the observed side must remain the
**natural** relay artefact. Editing both sides would make the decomposition
describe an edited pipeline rather than the deployed one.

## Selection bias of the observational estimator

For `T̄ ∈ (0,1)`:

```
R^obs − R̄₀  =  − Cov(T, R^-) / (1 − T̄)
```

A relay following a recoverability-aware allocation principle makes
`Cov(T, R^-)` more negative — so the better the relay, the larger the bias.
Observational reconstructability estimates are least trustworthy exactly where
the engineering is best.

## Why prior access needs a matched skeleton

Comparing a natural document with a value-randomised twin confounds prior access
with **context composition**, and forcing the focal atom absent in both arms
removes neither. Generating both arms from a common skeleton — identical slots
present, identical slots absent, matched position and length — makes the
context-composition term vanish, so the contrast identifies prior access alone.

Sufficiency of the matched skeleton is claimed. Necessity is claimed only within
the design class that varies the identity–value mapping without modelling the
relay's selection, not against all possible identification strategies.

## Estimation

Horvitz–Thompson requires the population size; the **Hájek** ratio form does not
and is the default, because the inventory size is known only up to atomiser
behaviour and the ratio is invariant to that.

An unweighted pooled mean is never correct here: role strata are sampled at
equal sizes while their inventory frequencies differ, so an unweighted mean
estimates the stratum-balanced population — and `R^-` varies strongly across
roles. Stratum-specific estimates and the weighted pooled estimate are both
reported.

Intervals are document-clustered bootstrap. Atoms are nested in documents and
share one realisation of the relay policy, so `n` is reported in **documents**.

## Sham correction and its sign

The artefact is modelled on the **mean-response** scale, since realised outcomes
are binary and an additive model on realisations is not closed in `[0,1]`:

```
μ^E_iz(w) − μ_iz(w) = ε_m + u_iz,    E[u_iz | m] = 0,   m ∈ {del, ins}
```

The correction is **mechanism-dependent in sign**. For a transmitted atom the
edited side produces `R^-`, which enters `Δ` negatively; for an omitted atom it
produces `D^+`, which enters positively. With `s_iz = 2·T_iz − 1`:

```
Δ_iz = Δ̂_iz + s_iz · ε_m(z)
```

Applying a common offset to both mechanisms would double-count the artefact on
one arm and cancel it on the other.

The region is a **population** statement. The placebo estimates a mechanism
average; the per-atom artefact carries mean-zero heterogeneity that the placebo
does not bound. An atom-level interval requires a separately stated bound.

## Availability versus budget-neutral

```
Δ^av_z = Y_z(1; M_-z)         − Y_z(0; M_-z)
Δ^bu_z = Y_z(1; M_{-z \ e})   − Y_z(0; M_-z)
```

They differ by the evicted atom's own effect, which is zero only if removing `e`
does not affect recovery of `z` — a condition that fails precisely under
in-message redundancy. A fixed-budget oracle fed `Δ^av` therefore optimises the
wrong objective, so the targeting experiment uses `Δ^bu` exclusively and is
gated.

`G*` is the **first-order surplus benchmark**, not the true causal optimum:
summing individually measured surpluses equals the joint allocation utility only
under approximate additivity, which the pairwise interaction diagnostic tests. If
interactions are large the oracle interpretation is dropped entirely and only
`Cov(T, Δ^bu)` is reported.

## Multi-hop

The decomposition applies verbatim at each hop. **Monotonicity does not follow.**
`T̄^(h)` is non-increasing only if relays cannot reintroduce an atom, and a
receiver that reconstructs `z` at hop `h` may cause it to be transmitted at hop
`h+1`. No data-processing claim is made: with fixed weights the chain remains
Markov, and decoding accuracy is not mutual information.
